# KobitoKey_QWERTY

KobitoKey のカスタムキーマップ（kako-junichi 用）。
ZMK ベース、ジェスチャーは廃止し、AeroSpace + Raycast ワークフロー寄せ構成。

## レイヤー一覧

| Layer | 名前 | 進入方法 |
|-------|------|----------|
| 0 | MAC | デフォルト |
| 1 | WIN | FUNC内の `bt_win` 押下で固定 |
| 2 | NUM | 左親指 SPACE 長押し |
| 3 | FUNC | 左小指 位置31 (旧TAB) 長押し |
| 4 | MOUSE | 右小指 位置38 長押し |
| 5 | SCROLL | A もしくは - 長押し |

## デフォルトレイヤー（Mac）

```
┌─────┬─────┬─────┬─────┬─────┐  ┌─────┬─────┬─────┬─────┬─────┐
│  Q  │  W  │  E  │  R  │  T  │  │  Y  │  U  │  I  │  O  │  P  │
├─────┼─────┼─────┼─────┼─────┤  ├─────┼─────┼─────┼─────┼─────┤
│A/SCR│  S  │  D  │  F  │  G  │  │  H  │  J  │  K  │  L  │-/SCR│
├─────┼─────┼─────┼─────┼─────┤  ├─────┼─────┼─────┼─────┼─────┤
│  Z  │  X  │  C  │  V  │  B  │  │  N  │  M  │  ,  │  .  │  /  │
├─────┼─────┼─────┼─────┼─────┤  ├─────┼─────┼─────┼─────┼─────┤
│LALT │FUNC │LCTRL│ SPC │ CMD │  │BSPC │ ENT │RSHFT│MOUSE│ssht │
│     │(mo) │     │/NUM │/IME │  │     │/Alt │     │(mo) │     │
└─────┴─────┴─────┴─────┴─────┘  └─────┴─────┴─────┴─────┴─────┘
```

- 元の `;` → `-` / 元の `'` → `/`（NUMで `;` `'` 取得可能）
- **A** および **`-`** 長押しで SCROLL レイヤー（両手から呼べる）

### 親指キー

| 位置 | キー | 動作 |
|------|------|------|
| 30 | LALT | Alt（小指） |
| 31 | FUNC | 長押しで FUNC レイヤー（小指） |
| 32 | LCTRL | Ctrl |
| 33 | SPACE/NUM | tap=SPACE / hold=NUM レイヤー |
| 34 | LCMD/IME | tap=Ctrl+Space (macOS入力ソーストグル) / hold=Cmd |
| 35 | BSPC | BackSpace |
| 36 | ENTER/Alt | tap=Enter / hold=Alt（AeroSpace用） |
| 37 | RSHFT | Shift |
| 38 | MOUSE | 長押しで MOUSE レイヤー（小指） |
| 39 | ss_ht | tap=Cmd+Shift+4 / hold=Cmd+Shift+5 |

## NUMレイヤー（SPACE長押し中）

```
┌─────┬─────┬─────┬─────┬─────┐  ┌─────┬─────┬─────┬─────┬─────┐
│  -  │  1  │  2  │  3  │  +  │  │  ^  │  &  │  ~  │  (  │  )  │
├─────┼─────┼─────┼─────┼─────┤  ├─────┼─────┼─────┼─────┼─────┤
│  /  │  4  │  5  │  6  │  0  │  │  !  │  @  │  #  │  $  │  ;  │
├─────┼─────┼─────┼─────┼─────┤  ├─────┼─────┼─────┼─────┼─────┤
│  *  │  7  │  8  │  9  │  \  │  │  [  │  ]  │  {  │  }  │  '  │
└─────┴─────┴─────┴─────┴─────┘  └─────┴─────┴─────┴─────┴─────┘
```

- `;` `'` `\` を NUM に集約
- `_` = Shift+`-`、`|` = Shift+`\`、`%` = Shift+5

## FUNCレイヤー（位置31長押し中）

```
┌─────┬─────┬─────┬─────┬─────┐  ┌──────┬──────┬─────┬──────┬──────────┐
│ F1  │ F2  │ F3  │ F4  │ F5  │  │bt_mac│bt_win│ MC  │BT_CLR│BT_CLR_ALL│
├─────┼─────┼─────┼─────┼─────┤  ├──────┼──────┼─────┼──────┼──────────┤
│ F6  │ F7  │ F8  │ F9  │ F10 │  │  ←   │  ↓   │  ↑  │  →   │    -     │
├─────┼─────┼─────┼─────┼─────┤  ├──────┼──────┼─────┼──────┼──────────┤
│ F11 │ F12 │  -  │  -  │  -  │  │  -   │  -   │  -  │  -   │    -     │
└─────┴─────┴─────┴─────┴─────┘  └──────┴──────┴─────┴──────┴──────────┘
```

| 機能 | 動作 |
|------|------|
| bt_mac | BT0プロファイル + Macレイヤー固定 |
| bt_win | BT1プロファイル + Winレイヤー固定 |
| MC | Mission Control (Ctrl+↑) |
| BT_CLR | 現在のBTプロファイルをクリア |
| BT_CLR_ALL | 全BTプロファイルをクリア |
| H/J/K/L | 矢印キー (←/↓/↑/→) |

## MOUSEレイヤー（位置38長押し中）

```
┌─────┬─────┬─────┬─────┬─────┐  ┌─────┬─────┬─────┬─────┬─────┐
│  -  │  -  │  -  │  -  │  -  │  │  -  │  -  │  -  │  -  │  -  │
├─────┼─────┼─────┼─────┼─────┤  ├─────┼─────┼─────┼─────┼─────┤
│  -  │ MB1 │ MB3 │ MB2 │  -  │  │  -  │ MB1 │ MB3 │ MB2 │  -  │
├─────┼─────┼─────┼─────┼─────┤  ├─────┼─────┼─────┼─────┼─────┤
│  -  │  -  │  -  │  -  │  -  │  │  -  │  -  │  -  │  -  │  -  │
└─────┴─────┴─────┴─────┴─────┘  └─────┴─────┴─────┴─────┴─────┘
```

- 38番（右小指）長押し中のみアクティブ（手動切替）
- 左手 S/D/F = MB1/MB3/MB2（左/中/右クリック）
- 右手 J/K/L = MB1/MB3/MB2（左/中/右クリック）

## SCROLLレイヤー（A or - 長押し中）

- 全キー透過
- **どちらのボールもスクロール挙動になる**
- A離す/- 離す → 通常モードへ復帰
- 旧左ボールと同じスクロール量

## コンボ一覧

| キー | 動作 | 用途 |
|------|------|------|
| Q + W | ESC | キャンセル/Vim |
| A + S | TAB | タブキー |
| D + F | LANG2(英数) | IME英数（Cmd-tapと冗長） |
| U + I | Ctrl+Shift+Tab | 前のタブ |
| I + O | Ctrl+Tab | 次のタブ |
| M + , | Cmd+[ | ブラウザ戻る |
| , + . | Cmd+] | ブラウザ進む |

タイムアウト: 50ms

## ホストツール側ショートカット

### Raycast（推奨）
- `Option+Space` で Raycast 起動（デフォルト）
- "Switch Windows" コマンド → 検索付きウィンドウ切替
- アプリ起動、計算、クリップボード履歴 etc

### AeroSpace（タイル型WM、ワークスペース1〜5）

| キー | 動作 |
|------|------|
| **Alt+H/J/K/L** | フォーカス移動（vim風 左/下/上/右） |
| **Alt+Shift+H/J/K/L** | ウィンドウ移動 |
| **Alt+1〜5** | ワークスペース1〜5へ切替 |
| **Alt+Shift+1〜5** | 選択中ウィンドウをワークスペース1〜5へ移動 |
| **Alt+Tab** | 直前のワークスペースに戻る |
| **Alt+,** | 分割向き切替（横⇔縦） |
| **Alt+/** | tiles ⇔ accordion 切替 |
| **Alt+Shift+Space** | floating ⇔ tiling 切替 |
| **Alt+F** | フルスクリーン |
| **Alt+M** | macOS native fullscreen |
| **Alt+R** | リサイズモード（h/j/k/l でサイズ調整、Esc/Enter で抜ける） |
| **Alt+Shift+;** | サービスモード（reload, flatten 等） |

### KobitoKey から AeroSpace を操作

| AeroSpace | KobitoKey 操作 |
|-----------|----------------|
| Alt+H/J/K/L | ENTER長押し + H/J/K/L |
| Alt+Shift+H/J/K/L | ENTER長押し + RSHFT長押し + H/J/K/L |
| Alt+1〜5 | ENTER長押し + SPACE長押し + W/E/R/S/D（NUM層の数字位置） |
| Alt+/ | ENTER長押し + SPACE長押し + A |
| Alt+, | ENTER長押し + `,` |
